# Civilizaciones de mod-minimal

Un archivo por civilización, con el estado REAL implementado (no el plan original — ver
`docs/civilization-design.md` para el diseño temprano, hoy superado en varios puntos). Cada
doc resume: civ base real que clona, rango de IDs, edificios/unidades propias, y
particularidades/deuda técnica conocida. La fuente de verdad más detallada sigue siendo la
memoria de cada civ (`aoe3-<civ>-civ-clones-*`) y el `CHANGELOG.md` — estos docs son un resumen
de consulta rápida, no reemplazan esas fuentes.
